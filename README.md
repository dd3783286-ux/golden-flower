# 好友炸金花（手机浏览器版）

纯娱乐好友房，不含人民币充值、提现、现金下注或任何可兑换资产。支持实时房间、最多 10 人、虚拟筹码审批与玩家借用、看牌/跟注/加注/弃牌/比牌和微信网页 OAuth。

## 当前房规与流程

- 底注固定为 1，加注档位为 1/2/5/10/20/50/100/200/500。
- 闷牌按当前档位支付，明牌按两倍支付；看牌免费且看牌后继续操作。
- 完成首轮下注后可比牌；费用按发起者的闷牌/明牌状态计算。
- 比牌双方的三张牌和牌型向全桌公开 3 秒；普通弃牌不公开。
- 不允许部分跟注，筹码不足时只能弃牌。
- 不同花色 235 默认只在遇到豹子时获胜；A23 是最小顺子，不比较花色。
- 每次操作限时 30 秒，掉线或超时不会永久锁住牌局。
- 玩家必须准备；至少 2 名在线、已准备且筹码足够的玩家才能开局。
- 玩家初始筹码为 0，可申请 100/200/300/500，由房主批准。
- 借筹码先由出借人确认，再由房主最终批准，并记录未还金额和还款。
- 等待时退出会真正离房；牌局中退出自动弃牌，本局后移出，房主退出会转让。
- 房间状态保存到 `data/rooms.json`，全部离线超过 2 小时的房间自动清理。

## 本地运行

```powershell
Copy-Item .env.example .env
npm install
npm test
npm start
```

电脑访问 `http://localhost:3000`。同一 Wi-Fi 下手机访问 `http://电脑局域网IP:3000`；Windows 防火墙可能需要放行 Node.js 的专用网络访问。

## 微信登录

真实微信登录不是个人微信号直接提供的能力，需要已认证的微信公众号：

1. 在公众号后台设置网页授权域名（必须是已备案 HTTPS 域名）。
2. 在 `.env` 设置 `BASE_URL`、`WECHAT_APP_ID`、`WECHAT_APP_SECRET`。
3. 正式环境设置 `ALLOW_DEV_LOGIN=false` 和高强度 `SESSION_SECRET`。

当前登录会话仍使用内存存储，适合试玩；房间状态已在本机持久化。正式上线仍应换成 Redis/数据库，并增加限流、监控与内容安全策略。
